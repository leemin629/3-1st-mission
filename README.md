# 🧳 전국 관광 데이터 월별 변동 패턴 대시보드

2018~2025년 전국 관광 방문자 수와 소비 데이터를 분석하여,
**월별·연도별·지역별 변동 패턴**을 한눈에 확인할 수 있는 인터랙티브 대시보드입니다.

Streamlit + Plotly 기반으로 제작되었으며, 4개의 탭으로 구성됩니다.

---

## 📌 주요 기능

| 탭 | 기능 |
|---|---|
| 🏠 소개 | 프로젝트 개요, 주요 발견, 데이터 출처 안내 |
| 📈 전국 월별 변화 | 연도·변수를 선택해 월별 추이를 비교 (다중 선택 지원) |
| 🗺️ 지역별 방문 변화 | 연도별 17개 광역시도 방문자 순위 + 지역별 추이 |
| 📊 전국 관광 소비 분석 | 관광 소비 항목별(숙박·식음료·쇼핑 등) 월별 추이 |

### 인터랙션 특징
- **전체 선택 토글**: 모든 연도/변수/지역을 한 번에 선택
- **pills 다중 선택**: 원하는 항목만 골라서 비교
- **다크 테마 그래프**: Plotly `plotly_dark` 템플릿 통일
- **반응형 레이아웃**: `use_container_width`로 화면 크기 자동 대응

## 🖼️ 화면 미리보기

### 전국 월별 변화
연도별로 색이 구분된 선그래프로, 5월·10월 정점의 계절성을 확인할 수 있습니다.

### 지역별 방문 변화
경기도(21.4%)·서울(20.4%)이 전체 방문자의 40% 이상을 차지합니다.

## 🧭 사용 방법

1. 상단 **탭**을 클릭해 원하는 분석 화면으로 이동합니다.
2. **연도 / 변수 / 지역** 을 선택(pills 클릭)해 그래프를 필터링합니다.
3. **전체 선택 토글**을 켜면 모든 항목이 한 번에 표시됩니다.
4. 그래프 우측 상단 아이콘으로 **확대·저장(PNG)** 이 가능합니다.

## 📊 데이터 설명

본 대시보드는 3개의 전처리 완료 데이터를 사용합니다.

### 1. `01_national_monthly.csv` — 전국 월별 집계
전국 단위 관광 지표를 연-월 단위로 집계한 데이터입니다.

| 컬럼 | 설명 |
|---|---|
| 연도 | 2018 ~ 2025 |
| 월 | 1 ~ 12 |
| 전체방문자수 | 전국 월별 총 방문자 수 |
| 관광총소비 | 전국 월별 총 관광 소비액 |
| 숙박업소비 | 숙박 관련 소비액 |
| 식음료업소비 | 식음료 관련 소비액 |
| 쇼핑소비 | 쇼핑 관련 소비액 |

### 2. `02_regional_wide.csv` — 지역별 방문자 (wide)
17개 광역시도별 방문자 수를 연도별로 정리한 데이터입니다.

| 컬럼 | 설명 |
|---|---|
| 광역지자체명 | 서울특별시, 경기도 등 17개 지역 |
| 2018 ~ 2025 | 각 연도별 방문자 수 |

### 3. `03_consumption.csv` — 관광 소비 항목
관광 소비를 항목별로 나눈 데이터입니다.

| 컬럼 | 설명 |
|---|---|
| 연도 / 월 | 시점 정보 |
| 숙박업소비 / 식음료업소비 / 쇼핑소비 | 항목별 소비액 |

## 🔎 주요 분석 결과

### 📈 전국 월별 변화
- 방문자 수와 소비 모두 **봄(5월)·가을(10월)** 에 정점을 보이는 뚜렷한 **계절성**이 나타납니다.
- 2020~2021년은 코로나19 영향으로 전 지표가 크게 하락했다가, 2022년부터 회복세를 보입니다.

### 🗺️ 지역별 방문 변화 (2025년 기준)
- **경기도(21.3%)** 와 **서울특별시(20.5%)** 두 지역이 전체 방문자의 **약 42%** 를 차지합니다.
- 수도권 집중 현상이 뚜렷하며, 세종특별자치시(1%)가 가장 낮습니다.
- 관광 명소가 많은 강원(4.9%)·경북(6.1%)은 비수도권 중 상위권입니다.

### 📊 전국 관광 소비 분석
- 소비 항목 중 **식음료업**과 **숙박업**이 큰 비중을 차지합니다.
- 소비 정점 시기가 방문자 수 정점(5월·10월)과 일치하여, **방문자 증가 → 소비 증가**의 연관성을 확인할 수 있습니다.

## 🛠️ 트러블슈팅

작업 중 자주 만난 문제와 해결 방법입니다.

| 문제 | 원인 | 해결 |
|---|---|---|
| 화면이 안 바뀜 / 이전 값 유지 | 캐시·상태 반영 지연 | 브라우저에서 **F5(새로고침)** |
| `IndentationError` | 들여쓰기(공백) 불일치 | 탭/스페이스 통일, 블록 정렬 확인 |
| 탭 내용이 안 보임 | `with tab:` 블록 누락·이탈 | 각 탭 코드가 올바른 `with` 안에 있는지 확인 |
| X축이 너무 촘촘함 | 월 단위 라벨 과다 | 연도 단위로 눈금 표시하도록 설정 |
| 그래프가 안 뜸 | 항목 미선택 | 연도·변수·항목을 최소 1개 이상 선택 |
