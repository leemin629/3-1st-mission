## 1. 분석 개요

### 1.1 분석 배경 및 목적

관광 수요와 소비는 1년을 주기로 일정한 높낮이를 반복하는 경향이 있다. 이러한 **연중 변동 패턴**을 정량적으로 파악하면, 성수기·비수기 구조를 이해하고 관광정책 및 산업 운영 전략의 기초자료로 활용할 수 있다.

본 분석의 목적은 다음과 같다.

- 전국 관광의 방문자수와 소비의 **연중 변동 패턴** 파악
- 방문·소비·업종별 **월별 증감** 구조의 차이 확인
- 코로나19 전후 시기별 변화 비교 (일회성 충격과 반복 패턴 구분)

### 1.2 분석 대상 기간 및 데이터

- **분석 기간:** 2018년 1월 ~ 2025년 12월 (8개 연도, 96개월)
- **데이터 출처:** 한국관광 데이터랩 기반 월별 집계자료
- **입력 파일:** `data/raw/` 폴더 내 총 48개 CSV (8개 기간 × 6종)

### 1.3 분석 변수

본 분석에서 사용한 주요 변수는 다음과 같다.

| 구분 | 변수명 | 설명 |

## 2. 분석 방법

### 2.1 분석 절차

분석은 다음 순서로 진행하였다.

1. **데이터 점검** — 원본 파일의 형식·구조·결측 확인
2. **변수 추출** — 분석 대상 5개 변수 정리
3. **월평균 산출** — 각 월의 평균값 계산
4. **월별 증감 계산** — 연간 평균 대비 각 월의 상대적 높낮이 산출
5. **시기별 비교** — 세 구간의 변동 패턴 비교

### 2.2 월별 증감의 산출 방식

각 월의 증감은 해당 월의 평균값을 연간 평균과 비교하여 산출하였다. 값이 연간 평균보다 높으면 (+), 낮으면 (−)로 나타난다.

> **해석상의 유의점**
> 월별 증감 값 사이의 **작은 차이(예: 0.3 수준)** 는 통계적 변동 범위 내일 수 있으므로, 이를 구조적 변화로 확대 해석하지 않는다. 본 보고서는 **뚜렷한 방향성이 확인되는 경우에만** 해석을 부여한다.

### 2.3 분석 도구

- **언어:** Python
- **주요 라이브러리:** pandas, matplotlib
- **핵심 분석 코드:** `src/seasonality_analysis.py`



## 3. 분석 결과

### 3.1 전체 방문자수의 연중 변동 패턴

전국 방문자수는 1년을 주기로 뚜렷한 높낮이를 반복하였다. 값이 높은 시기와 낮은 시기가 매년 유사한 형태로 되풀이되어, 안정적인 **연중 변동 패턴**을 확인할 수 있었다.

| 월 | 월별 증감 | 경향 |
|---|---|---|
| 1월 | − | 낮음 (비수기) |
| 2월 | − | 낮음 |
| 3월 | + | 상승 전환 |
| 4월 | + | 봄철 상승 |
| 5월 | + | 높음 |
| 6월 | + | 유지 |
| 7월 | + | 여름 상승 |
| 8월 | + | 높음 (성수기) |
| 9월 | + | 유지 |
| 10월 | + | 높음 (가을 성수기) |
| 11월 | − | 하락 전환 |
| 12월 | − | 낮음 |

> **해석:** 방문자수는 **봄(5월)·여름(8월)·가을(10월)** 에 값이 높고, **겨울(1~2월, 12월)** 에 낮은 형태가 반복된다. 5월·8월·10월의 증감 값은 서로 근소한 차이를 보이므로, 특정 한 계절이 압도적이라고 단정하기보다 **연중 여러 시기에 고르게 높다**고 해석하는 것이 타당하다.

### 3.2 관광총소비의 연중 변동 패턴

관광총소비 역시 방문자수와 유사한 연중 변동 패턴을 보였으나, 소비는 방문보다 **월별 증감의 진폭이 다소 컸다.**

| 시기 | 월별 증감 경향 |
|---|---|
| 봄 (3~5월) | + 상승 |
| 여름 (6~8월) | + 높음 |
| 가을 (9~10월) | + 높음 |
| 겨울 (11~2월) | − 낮음 |

> **해석:** 소비는 방문과 비슷한 리듬을 따르되, 성수기의 증가폭과 비수기의 감소폭이 더 뚜렷하다. 이는 방문객 1인당 지출이 성수기에 더 집중됨을 시사한다.

### 3.3 업종별 연중 변동 패턴 비교

숙박·식음료·쇼핑 세 업종은 서로 다른 연중 변동 패턴을 나타냈다.

| 업종 | 높은 시기 | 특징 |
|---|---|---|
| **숙박업** | 여름(7~8월), 가을(10월) | 휴가철 집중, 월별 증감 진폭 큼 |
| **식음료업** | 연중 고르게 분포 | 월별 증감 진폭 작음 (안정적) |
| **쇼핑** | 봄·가을 | 나들이 시기와 연동 |

> **해석:**
> - **숙박업**은 휴가·여행 시기에 값이 집중되어 연중 변동 패턴이 가장 뚜렷하다.
> - **식음료업**은 계절과 무관하게 꾸준한 수요를 보여 월별 증감이 완만하다.
> - **쇼핑**은 외출이 늘어나는 봄·가을에 상대적으로 높다.

## 4. 시기별 비교 (코로나19 전후)

### 4.1 세 구간의 연중 변동 패턴 비교

| 구간 | 연중 변동 패턴 | 값의 수준 |
|---|---|---|
| 코로나 이전 (2018~2019) | 안정적·전형적 | 기준선 |
| 코로나 영향기 (2020~2021) | **패턴 붕괴** | 급락 |
| 회복기 (2022~2025) | 이전 패턴으로 복귀 | 기준선 이상 회복 |

### 4.2 코로나 영향기의 해석 — 일회성 충격

코로나 영향기(2020~2021)의 값은 다른 시기와 크게 달랐다. 그러나 이는 **반복되는 연중 변동 패턴의 일부가 아니라, 해당 시기에만 발생한 일회성 충격**이다.

> **중요:** 코로나 영향기의 급락은 연중 변동 패턴으로 해석해서는 안 된다.
> - 매년 반복되는 형태가 아니라 **특정 시기에만 나타난 예외적 변동**이기 때문이다.
> - 따라서 이 구간의 수치는 패턴 분석에서 **별도의 특수상황**으로 다룬다.

### 4.3 회복기의 특징

회복기(2022~2025)에는 코로나 이전의 연중 변동 패턴이 다시 나타났다. 값의 높낮이 형태가 2018~2019년과 유사하게 복원되어, **연중 변동 패턴 자체는 견고하게 유지됨**을 확인할 수 있었다.

## 5. 종합 결론

### 5.1 주요 발견

본 분석을 통해 확인한 핵심 내용은 다음과 같다.

1. **전국 관광은 뚜렷한 연중 변동 패턴을 보인다.**
   - 방문·소비 모두 봄·여름·가을에 값이 높고 겨울에 낮은 형태가 매년 반복된다.

2. **성수기는 특정 한 계절에 집중되지 않는다.**
   - 5월·8월·10월의 월별 증감이 근소한 차이를 보여, 연중 여러 시기에 고르게 높다.

3. **업종별로 연중 변동 패턴이 다르다.**
   - 숙박업은 변동 진폭이 크고, 식음료업은 완만하며, 쇼핑은 봄·가을에 높다.

4. **코로나19는 일회성 충격이었다.**
   - 영향기의 급락은 반복 패턴이 아니며, 회복기에 이전 패턴이 복원되었다.

### 5.2 시사점

- **관광정책:** 연중 변동 패턴을 고려하여 비수기(겨울) 수요 진작 전략이 필요하다.
- **산업 운영:** 업종별 변동 특성이 다르므로, 숙박업은 성수기 집중 대응, 식음료업은 안정적 운영 전략이 유효하다.
- **위기 대응:** 코로나19 사례처럼 일회성 충격은 패턴과 구분하여 별도로 관리해야 한다.

### 5.3 분석의 한계

본 분석은 다음과 같은 한계를 가진다.

1. **기후·날씨 데이터 부재**
   - 본 보고서의 "연중 변동 패턴"은 값의 반복 형태를 의미할 뿐, 기후적 요인과의 인과관계는 분석하지 못했다.

2. **월별 증감의 정밀 분해 미실시**
   - 추세·순환·불규칙 요인을 통계적으로 완전 분리(예: STL 분해)하지 않았다. 월별 증감은 연간 평균 대비 상대값으로 산출한 것이다.

3. **작은 차이의 해석 제한**
   - 월별 증감 간 근소한 차이는 통계적 변동 범위일 수 있어, 구조적 변화로 해석하지 않았다.

### 5.4 향후 과제

- 기후·이벤트·요일 등 **외부 요인 데이터를 결합**한 심화 분석
- **STL 등 시계열 분해 기법**을 적용한 추세·변동 요인의 정밀 분리
- 지역별 연중 변동 패턴 비교 분석
