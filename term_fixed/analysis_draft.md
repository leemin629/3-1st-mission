# 관광 월별 월별 변동 패턴 및 연간 구조 변화 분석

## 1. 분석 목적

본 분석의 목적은 전국 관광의 **월별 월별 변동 패턴**을 파악하고, 관광 수요와 소비가 계절에 따라 어떻게 변하는지를 확인하는 데 있다.  
또한 연도별 **지역·업종 구조 변화**를 함께 살펴봄으로써 관광 소비의 분포가 장기적으로 어떻게 달라지는지도 보조적으로 분석하고자 한다.

### 주요 분석 질문
- 관광 방문자 수는 월별로 어떤 월별 변동 패턴을 보이는가?
- 관광총소비는 방문자 수와 유사한 흐름을 보이는가?
- 숙박과 식음료 소비는 어떤 월별 차이를 보이는가?
- 쇼핑 소비는 왜 메인 지표가 아닌 보조지표로 해석해야 하는가?
- 지역별·업종별 지출 비중은 연도별로 어떤 구조 변화를 보이는가?

## 2. 데이터 설명
- 월별 데이터 파일: monthly_tourism.csv
- 연도별 비중 데이터 파일: yearly_share.csv
- 분석 기간: 2018.01 ~ 2025.12
- 주요 변수: 날짜, 방문자수, 관광총소비, 호텔, 콘도, 캠핑장/펜션, 기타숙박, 일반외식업, 제과음료업

원본 데이터(raw)는 연도별 6개 파일로 구성됨.

- 관광소비 추이
- 방문자 수 추이
- 업종별 지출액
- 지역별 방문자 수(광역)
- 지역별 방문자 수(기초)
- 지역별 지출액

분석 기간: 2018.01 ~ 2025.12
총 파일 수: 8년 × 6종 = 48개

### 2.1 사용 데이터
본 분석에서는 관광 관련 **월별 시계열 자료**와 **연도별 비중 자료**를 활용한다.

- 월별 자료: 방문자 수, 관광총소비, 업종별 소비액

### 2.2 분석 기간

## 3. 변수 정의 및 구성

본 분석에서는 변수를 **메인·보조 분석 변수**와 **파생변수**로 구분하여 구성하였다.  
메인 변수는 월별 월별 변동 패턴 분석의 핵심 지표이며, 보조 변수는 구조적 변화 설명 또는 보완적 해석을 위한 참고 지표로 활용한다.

### 3.1 최종 변수 목록 표

#### ① 메인·보조 분석 변수 표

| 구분 | 변수명 | 구성/정의 | 분석 역할 | 비고 |
|---|---|---|---|---|
| 메인 | 방문자수 | 월별 관광 방문자 수 | 관광 수요의 유입 규모 파악 | 월별 변동 패턴 핵심 지표 |
| 메인 | 관광총소비 | 월별 전체 관광소비 금액 | 관광활동의 전체 규모 파악 | 월별 변동 패턴 핵심 지표 |
| 메인 | 숙박합계 | 호텔 + 콘도 + 캠핑장/펜션 + 기타숙박 | 체류형 관광 소비 파악 | 월별 변동 패턴 반응이 비교적 뚜렷할 가능성 |
| 메인 | 식음료합계 | 일반외식업 + 제과음료업 | 현지 활동 소비 파악 | 관광 중 소비활동 보조 설명 |
| 보조 | 쇼핑합계 | 쇼핑 관련 세부 업종 합계 | 쇼핑 소비 흐름 참고 | 면세점·정책·외부환경 등 변동요인 많아 보조지표로 사용 |
| 보조 | 지역별 지출 비중 | 연도별 지역별 소비 비중 | 지역 구조 변화 설명 | 월별 월별 변동 패턴 분석용은 아님 |
| 보조 | 업종별 지출 비중 | 연도별 업종별 소비 비중 | 업종 구조 변화 설명 | 월별 월별 변동 패턴 분석용은 아님 |

#### ② 파생변수 표

| 구분 | 변수명 | 산식/정의 | 목적 |
|---|---|---|---|
| 파생 | 월 | 날짜에서 월 추출 | 월별 평균 패턴 계산 |
| 파생 | 방문자수지수 | 방문자수 / 2018년 1월 값 × 100 | 단위가 다른 지표 비교 |
| 파생 | 총소비지수 | 관광총소비 / 2018년 1월 값 × 100 | 시계열 비교 |
| 파생 | 숙박지수 | 숙박합계 / 2018년 1월 값 × 100 | 월별 변동 패턴 강도 비교 |
| 파생 | 식음료지수 | 식음료합계 / 2018년 1월 값 × 100 | 월별 변동 패턴 강도 비교 |
| 선택 파생 | 쇼핑지수 | 쇼핑합계 / 2018년 1월 값 × 100 | 보조 그래프 비교용 |

### 3.2 변수 선정 이유

#### 메인 변수 선정 이유
- **방문자수**: 관광 수요 규모를 직접적으로 보여주는 기본 지표
- **관광총소비**: 관광 활동의 전체 소비 규모를 보여주는 대표 지표
- **숙박합계**: 체류형 관광의 특성을 반영하며 월별 변동이 비교적 뚜렷할 가능성이 높음
- **식음료합계**: 관광 중 현지 활동과 밀접한 소비로 방문 흐름과의 연관성 파악에 적합함

#### 쇼핑을 보조 변수로 둔 이유
쇼핑 소비는 관광 소비의 일부이지만 월별 변동 패턴 해석의 핵심 지표로 사용하기에는 한계가 있다.

- 면세점 소비 비중 등 특정 업종 영향이 크게 작용할 수 있음
- 정책 변화, 환율, 국제 이동 여건 등 외부 요인의 영향을 크게 받을 수 있음
- 월별 변동 패턴보다 비계절적 충격이나 구조적 변화가 더 크게 반영될 가능성이 있음

따라서 쇼핑은 분석에서 제외하지 않되, **메인 지표가 아닌 보조지표**로 활용한다.

## 4. 분석 방법

### 4.1 전처리 방향
월별 월별 변동 패턴 비교를 위해 다음과 같은 전처리를 수행한다.

- 월별 데이터 정리
- 날짜 변수에서 월 추출
- 업종 합산을 통해 숙박합계, 식음료합계, 쇼핑합계 생성
- 시계열 순서 정렬
- 결측치 및 이상치 확인
- 지수화 변수 생성

### 4.2 지수화 기준
서로 단위와 규모가 다른 변수들을 비교하기 위해 **2018년 1월=100** 기준으로 지수화한다.

지수 산식은 다음과 같다.

\[
지수 = \left(\frac{해당월 값}{2018년 1월 값}\right) \times 100
\]

이를 통해 방문자수, 관광총소비, 숙박합계, 식음료합계의 상대적 변화 패턴을 직접 비교할 수 있다.

### 4.3 월별 월별 변동 패턴 분석 방법
월별 월별 변동 패턴 분석은 다음 순서로 진행한다.

1. 방문자수의 월별 추이를 통해 관광 수요의 기본 월별 변동 패턴을 확인한다.
2. 관광총소비의 월별 추이를 통해 소비 규모의 월별 변동 패턴을 확인한다.
3. 숙박합계와 식음료합계를 비교하여 소비 항목별 월별 변동 패턴 차이를 본다.
4. 지수화 그래프를 통해 주요 지표의 상대적 변동 폭을 비교한다.
5. 월평균 패턴을 통해 반복적인 계절 구조를 확인한다.
6. 쇼핑합계는 보조 그래프로 제시하고 참고 수준에서 해석한다.

### 4.4 연간 구조 변화 분석 방법
연도별 자료를 활용하여 다음 내용을 보조적으로 분석한다.

- 지역별 지출 비중 변화
- 업종별 지출 비중 변화

이는 월별 월별 변동 패턴을 설명하는 핵심 분석은 아니지만, 관광 소비 구조가 장기적으로 어떻게 달라졌는지 이해하는 데 도움을 준다.

## 5. 그래프 구성안

본 분석에서는 총 4~6개의 그래프를 중심으로 결과를 제시한다.

### 5.1 월별 월별 변동 패턴 그래프
1. **방문자수 월별 추이**
   - 관광 수요의 전반적 월별 변동 패턴 확인
   - 성수기와 비수기, 반복적 월 패턴 파악

2. **관광총소비 월별 추이**
   - 전체 소비 규모의 월별 변동 패턴 확인
   - 방문자수와의 흐름 비교

3. **숙박합계 vs 식음료합계 추이**
   - 소비 항목별 계절 반응 차이 비교
   - 체류형 소비와 활동형 소비 차이 확인

4. **주요 지표 지수화 비교 그래프**
   - 방문자수지수, 총소비지수, 숙박지수, 식음료지수 비교
   - 어떤 지표가 계절 변화에 더 민감한지 확인

5. **월평균 월별 변동 패턴 그래프**
   - 동일 월의 평균 패턴 비교
   - 특정 월의 일관된 강세·약세 확인

6. **쇼핑합계 보조 그래프**
   - 쇼핑 소비 흐름 참고
   - 다른 지표와 다른 방향성이 나타나는지 확인

### 5.2 연간 구조 변화 그래프
7. **지역별 지출 비중 그래프**
   - 지역별 소비 비중의 연도별 변화 확인

8. **업종별 지출 비중 그래프**
   - 업종 구조의 연도별 변화 확인

## 6. 결과 해석 방향

### 6.1 기본 해석 원칙
분석 결과는 단순한 값의 크기보다 **월별 반복 패턴**과 **상대적 변화 폭**을 중심으로 해석한다.

### 6.2 해석 시 유의점
- 방문자수 증가가 반드시 동일한 폭의 소비 증가로 이어지지는 않을 수 있음
- 숙박 소비는 체류형 관광의 영향을 더 직접적으로 반영할 가능성이 있음
- 식음료 소비는 일부 생활 소비와 혼재될 수 있으므로 상대 비교 중심으로 해석
- 쇼핑 소비는 외부환경의 영향이 커서 월별 변동 패턴 자체보다 변동성 참고용으로 해석
- 지역별·업종별 비중은 구조 변화 설명용이며 월별 월별 변동 패턴 지표와는 구분해서 해석해야 함

### 6.3 보고서용 해석 문장 예시
- 방문자수는 특정 성수기에 뚜렷한 증가를 보이며 전형적인 월별 변동 패턴을 나타냈다.
- 관광총소비는 전반적으로 방문자수와 유사한 흐름을 보였으나, 일부 시기에는 소비 규모의 변동 폭이 더 크게 나타났다.
- 숙박합계는 식음료합계보다 월별 변동이 더 뚜렷하게 나타나 체류형 관광 수요의 영향을 상대적으로 강하게 반영하는 것으로 해석된다.
- 쇼핑합계는 다른 지표와 비교할 때 월별 변동 패턴보다 외부 환경 변화의 영향을 더 크게 받을 가능성이 있어 보조지표로 해석하는 것이 적절하다.
- 지역별 지출 비중과 업종별 지출 비중은 관광 소비 구조의 장기적 변화를 보여주는 참고 자료로 활용할 수 있다.

## 8. 예상 결론

본 분석을 통해 관광의 월별 월별 변동 패턴은 방문 규모뿐 아니라 소비 항목별로도 다르게 나타날 가능성이 높다.  
방문자수와 관광총소비는 전체 흐름을 설명하는 핵심 지표이며, 숙박합계와 식음료합계는 관광 활동의 성격 차이를 보여주는 보완 지표로 의미가 있다.  
반면 쇼핑합계는 외부 변수의 영향이 크므로 주요 월별 변동 패턴 판단 기준이라기보다 보조적 참고 지표로 활용하는 것이 적절하다.  
또한 지역별·업종별 지출 비중 분석은 월별 월별 변동 패턴 분석을 보완하면서 관광 소비 구조의 연도별 변화를 설명하는 데 유용하다.
